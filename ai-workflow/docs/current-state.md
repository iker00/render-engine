# Estado actual

## Capacidades disponibles
- Flujo documental base de `ai-workflow` disponible.
- Contexto del producto ya orientado a la nueva app de UI configurable.
- No existe todavía implementación funcional del runtime en `src/`.

## Límites actuales
- El renderer declarativo aún no está implementado.
- No hay estructura de código establecida para `Vite`, `React` y `Tailwind`.
- No existe todavía validación runtime de configuración ni panel de desarrollo local.
- No hay integración real con backend; el contrato documental asume recepción futura por `data-config`.

## Infraestructura vigente
- Repositorio preparado para trabajar con documentación guiada por specs.
- Estándares de testing, estilo, errores y seguridad definidos en `ai-workflow/standards/`.
- Pendiente de bootstrap técnico de la aplicación frontend y de apertura de las primeras features del workflow.
